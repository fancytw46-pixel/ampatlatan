# Multi-Threaded Performance & Network Tunneling Benchmark Test

This repository is dedicated to benchmarking and testing network latency and multi-threaded CPU performance on distinct environment baselines. The goal is to analyze overhead spikes during long-running tasks under controlled environments.

## 🛠️ Project Architecture

The suite consists of automated workflow routines designed to evaluate:
- High-concurrency computational loops.
- Virtual network interface throughput using modern tunneling protocols.
- UI render engine pipeline optimization simulation under heavily constrained server instances.

## 🚀 How to Run Benchmarks Manually

To manually trigger the automated benchmark runner suite:
1. Navigate to the **Actions** tab in this repository.
2. Select the `Windows AE Runner` workflow.
3. Click on the **Run workflow** dropdown menu and initiate the workflow.
